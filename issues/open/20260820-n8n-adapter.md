# n8n Workflow Adapter 実装構想

Status: open
Date: 2026-08-20
Target: Artifact Studio

## Goal

Artifact Studio から n8n workflow JSON を生成・編集・検証・保存・書き出しし、将来的には n8n instance への deploy/update まで行える adapter を追加する。

```text
prompt / import
  -> n8n workflow JSON
  -> validate
  -> layout / format
  -> preview / edit
  -> persist
  -> export
  -> optional deploy
```

## Canonical artifact

n8n が import/export で扱う workflow JSON を canonical artifact とする。

独自 DSL は作らず、n8n workflow JSON を直接保存・exportする。

内部では deploy 対象と portable artifact を分離する。

- portable source: node / connection / settings 等の workflow 定義
- instance metadata: workflow id, active state, credentials binding 等

instance 固有 ID や credential secret を portable artifact に埋め込まない。

## Adapter capabilities

```ts
interface N8nAdapter {
  id: 'n8n';
  import(source: string): N8nWorkflow;
  generate(prompt: string): Promise<N8nWorkflow>;
  validate(workflow: N8nWorkflow): ValidationResult;
  format(workflow: N8nWorkflow): N8nWorkflow;
  render(workflow: N8nWorkflow, host: HTMLElement): Promise<void>;
  serialize(workflow: N8nWorkflow): string;
  exportFileName(workflow: N8nWorkflow): string;
  deploy?(workflow: N8nWorkflow, target: DeploymentTarget): Promise<DeploymentResult>;
}
```

## UI

- Header adapter selector に `n8n` を追加
- node graph preview
- JSON source editor
- `AIで生成`
- `検証`
- `整形`
- workflow JSON import/export
- 将来 `n8nへ反映` ボタンを追加

初期版では n8n 本体の editor を再実装しない。graph は read-mostly preview とし、詳細編集は JSON/source editor を優先する。

## AI generation

専用 endpoint:

```text
POST /api/v1/artifacts/n8n/generate
```

Codex には次を明示する。

- 利用可能 node type/version を入力 context で制約
- credentials の secret 値は生成禁止
- expression syntax を壊さない
- instance 固有 workflow id は生成しない
- unsupported community node は明示許可がない限り使わない

AI output は JSON Schema / semantic validator を通過するまで artifact として採用しない。

## Validation

### Structural

- valid JSON
- `nodes` array
- `connections` object
- node name uniqueness
- connection target existence
- required node fields

### Semantic

- node type / typeVersion compatibility
- required parameters
- expression references
- unreachable nodes / orphan nodes
- trigger node existence
- credential references の整合

### Deployment validation

instance 接続時のみ:

- target n8n version
- installed node types
- credential availability
- environment-specific variables

## Formatting / layout

`position: [x, y]` を deterministic に再配置する formatter を持つ。

候補:

- ELK を共通 layout engine として再利用
- directed graph として left-to-right 配置
- trigger を左端
- branch / merge をレイヤー化
- sticky note / annotation は別処理

AI には座標を生成させず、BPMN と同様に deterministic formatter に任せる。

## Deployment

初期版は export のみ。
次段階で n8n API / MCP adapter を追加する。

```text
Artifact Studio
  -> n8n adapter
  -> validate against target
  -> diff
  -> explicit user confirmation
  -> create/update workflow
```

update 時は workflow ID を source artifact ではなく deployment binding で保持する。

## Security

- credential secret を artifact / prompt / localStorage に保存しない
- credential は logical name / binding key のみ
- import JSON に credential material が含まれる場合は警告または除去
- deploy は明示操作のみ
- target URL / token は server-side config または secret store で保持
- AI が arbitrary code node を生成する場合は追加警告

## Persistence

Artifact Studio workspace storage に workflow JSON を保存する。

大きな workflow / 複数workflow履歴が必要になった場合は IndexedDB へ移行する。

## Open questions

- n8n version ごとの node schema をどこから取得するか
- built-in node metadata を runtime n8n instance から取得するか package から取得するか
- Code node を初期adapterで許可するか
- sub-workflow / Execute Workflow dependency の扱い
- credential binding の portable naming convention
- deploy 時の create/update 判定

## Acceptance criteria

- [ ] n8n workflow JSON を import/exportできる

- [ ] deterministic layout で node position を整形できる
- [ ] graph preview ができる
- [ ] credential secret を保存しない
- [ ] browser persistence / restore ができる
